Groq Demo Chatbot 🤖

A simple demo chatbot built using Groq AI models to demonstrate natural language interaction capabilities. This project showcases how to integrate Groq models into a Python application and interact with them in real-time.

Features

Sends user input to a Groq AI model and returns responses.

Supports basic conversation flow.

Easy to extend for custom prompts and pipelines.

Lightweight and beginner-friendly.

Tech Stack

Python 3.12+

Groq AI SDK

LangChain for chaining prompts and responses.
